# 大手サイトとの比較・改善記録（2026-10-09）

対象はトップ、大学一覧、大学別数学模試の案内・全10大学の模試ページ、共通ナビゲーション・フッター。初見で用途が分かること、必要な情報まで短く移動できること、提供物の実体が見えることを優先した。

## 比較した公式サイト

- [河合塾・模試ラインアップ](https://www.kawai-juku.ac.jp/zento/lineup/): 学年・目的ごとに選ぶ入口、受験方法と申込案内を区別している。
- [駿台・模試案内](https://www2.sundai.ac.jp/moshi/): 実施日程・申込、申込済みの人、料金・FAQ、学校向け案内を分けている。
- [駿台・高3／高卒生の模試一覧](https://www2.sundai.ac.jp/yobi/sv/sundai/moshi_P/moshi_grade_PD/1337364908752.html): 模試名、受験日、申込期間を同じ形式で比較できる。
- [東進・模試案内](https://www.toshin-moshi.com/): 受付中の模試を前に置き、対象別の切替と日程・締切の一覧がある。

河合塾はブラウザでの撮影がアクセス制限によりできなかったため、公開ページの本文・リンク構造を比較した。駿台はスマートフォン表示、東進はPC表示も確認した。東進の当該ページはスマートフォン幅でも横幅が広く、他社で使われている表現をそのまま採用することが最善とは限らない。

## 現サイトの課題と実装

| 課題 | 改善 |
|---|---|
| トップの検索欄まで、サイト説明と重複した数字を読む必要がある | 用途を短文で示し、無料の出題分析／模試の入口を主画面へ。詳しい実績数はサイト説明へ集約 |
| トップの大学候補がスマホで縦に並ぶ | 入口の4件を2列表示。検索・区分選択時には該当する全件を表示 |
| 大学一覧でも検索前に紹介文と重複した数字が続く | 紹介文を検索後に移動し、数字は冒頭の要点帯に集約 |
| 模試案内を上から読まないと、日程・料金・見本に到達しにくい | 案内の直下にページ内メニューを設置。大学別ページにも日程・見本・FAQ・申込の入口 |
| 模試の見せ方が装飾の答案図と文字中心 | 公開中の返却PDFをPCの主画面に表示。見本の表・裏はスマホでも2枚の小さな画像で常時提示 |
| 横向き成績表はスマホの全体表示では文字が小さい | 見本拡大画面に「文字を拡大」を追加。横・縦にスクロールして読める |
| フッターに長い説明文がまとまっている | 分析・解説・模試・教材・団体・個人情報・問い合わせをリンク一覧に。非公式である旨は常時表示し、詳細だけ折りたたみ |
| 無料資料と、名前に「模試」が入る購入教材を混同しやすい | 用件別カードに「無料のWeb資料」「書籍・購入教材」を表示 |
| 320px幅の教材一覧が555pxまで横にはみ出す | グリッドの最小幅とAmazonボタンのスマホ非表示を修正。書籍の行リンクは維持 |
| 押しにくい小さな操作と、キーボードで現在地が分かりにくい箇所 | 検索の消去、区分選択、模試の大学選択、見本操作を44px以上に。フォーカス表示と見本内のフォーカス移動・復帰を追加 |

## 維持したもの

大学別数学研究室というサイト名と、入試プレビューというシリーズ名を維持。他社の写真・ロゴ・配色・レイアウトの複製は行わない。価格・実施予定・判定の意味・統計の掲載条件・架空の見本という注意は変更しない。

合格実績、推薦、統計的な合格確率、受付締切、返却日、受験者用マイページなど、根拠や実装のない情報・機能を追加しない。受信メール転送やStripe設定は今回のデザイン変更とは別件で、確認済みとして扱わない。

## 操作上の参考

見本の拡大表示は、[W3Cのモーダルダイアログの操作指針](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)を参考に、初期フォーカス、Tabの循環、Escapeで閉じる操作、元のリンクへの復帰を確認する。

見た目と移動距離の検証はできるが、申込率向上はA/Bテストやアクセス解析での追跡が別途必要。デザインだけで成果が保証されるものではない。

スマートフォン幅375pxのトップで、検索欄の位置は約733pxから約595pxへ、ページ全体は5,517pxから約5,004pxへ改善（ブラウザでの初期表示、同じ書体・表示条件）。重要情報や詳細を削除して短くしたわけではなく、重複説明の整理と入口の配置で改善した。

## 利用者のフィードバックによる入口の再調整

「無料」の訴求が押しつけに感じられる、モバイルではメニューを開くまで分析サイトと分かりにくいという指摘を受け、トップを再調整した。

- 「無料」のボタン・帯・資料ラベルを外し、冒頭の見出しを「大学別の数学入試分析」に変更。サイト名はヘッダー・メタデータで維持する。
- モバイルでは非表示だった図を、掲載データから取得した名古屋大学理系の分析抜粋に置き換える。年度・試験時間・大問数・頻出分野を示し、分析ページへ直接リンクする。
- 大学検索を直下へ置き、模試の告知は検索の後の控えめなリンクにする。分析そのものは隠さず、任意の区分絞り込みと掲載範囲の説明だけを折りたたむ。
- 幅320px・高さ568pxでも、見出し・分析抜粋・検索欄が初期画面内に収まることを確認。幅375pxの検索欄は約595pxから約412pxへ、トップ全体は約5,004pxから約4,879pxへ変化した。

これは表示・移動距離の改善であり、離脱率の変化はアクセス解析での確認が必要。
