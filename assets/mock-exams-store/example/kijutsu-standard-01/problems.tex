\begin{daimon}{1}
$a$ を正の定数とし，関数 $f(x)=x^{3}-3ax^{2}+4$ を考える。以下の問いに答えよ。
\begin{shomon}
  \item $f(x)$ の極値を求めよ。\hfill（8点）
  \item 方程式 $f(x)=0$ が異なる3つの実数解をもつような $a$ の値の範囲を求めよ。\hfill（7点）
  \item $0\leqq x\leqq3$ における $f(x)$ の最小値 $m(a)$ を求めよ。\hfill（10点）
\end{shomon}
\end{daimon}
