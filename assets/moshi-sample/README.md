# 模試の返却サンプル

返却見本は問題・解答・採点基準の冊子とは別の、カラーの A4 成績冊子です。印刷物として読みやすい白地・細い罫線・表を中心とし、サイト既存の独自ロゴをヘッダーに入れています。

- 1ページ目：個人成績表。総合得点、分野別・設問別の得点、学習上の留意点。
- 2ページ目：答案講評・学習の手引き。設問番号に即した短評、2週間の復習予定。

返却資料には、この成績冊子と**採点済み答案**が含まれます。提出答案へ小問ごとの点数・添削・コメントを書き込み、別添PDFとして返却します。公開見本は成績冊子の2ページであり、実際の受験者の答案や架空の手書き答案を流用したものではありません。

受験者・得点・答案講評はすべて架空です。大問1（数列）は公開している見本問題に対応し、大問2（ベクトル）・大問3（確率）は返却形式を示すための例です。60点はこの架空例の配点で、実際の各大学の模試の満点を示すものではありません。平均点・偏差値・順位や合否判定を架空で作ってはいません。

## 参考にした公式資料

- [河合塾・全統模試の個人成績表](https://www.kawai-juku.ac.jp/zento/grades/report/)：成績概況、設問／分野別の結果、学習アドバイスの整理。
- [駿台模試・提供資料](https://www2.sundai.ac.jp/moshi/provided-materials/)：成績表の区画分け、グラフ、答案に即した短いコメント。
- 駿台の公式見本：[個人成績表](https://www2.sundai.ac.jp/moshi/img/sample_01.jpg)、[採点済み答案](https://www2.sundai.ac.jp/moshi/img/sample_02.jpg)、[採点講評](https://www2.sundai.ac.jp/moshi/img/sample_04.jpg)。表の組み方、発行元の表示、成績表と採点答案を区別する構成を参考にしました。
- [河合塾・全統記述模試の個人成績表の見方](https://www.kawai-juku.ac.jp/zento/pdf/2nd-kijutsu04-antenna.pdf)：成績概況、設問別成績、復習指針の情報整理。
- [河合塾・名大入試オープン](https://www.kawai-juku.ac.jp/zento/lineup/gd3/nagoya02/)：個人成績表と学習の手引きを用いた復習へのつなぎ方。

各社のロゴ、成績表の画像、文章や固有の判定指標は流用せず、情報の順序と整理の考え方を参考にしています。
「できた点・確認する点・次の一手」のカード形式や分野ごとの色帯は使わず、設問番号に沿った文章と罫線表に整理しています。ロゴは `components/logo.tsx` の既存のものと同じ形を PDF 内にもベクターで描いています。

## 更新方法

内容は `data/moshi-return.json`、PDF のレイアウトは `moshi-return.tex`、Web の概要は `components/moshi-return-sample.tsx` にあります。得点・配点は小問から集計し、Web と PDF で同じデータを使います。

`npm run moshi:sample` で PDF・WebP・ページ一覧を生成します。LuaLaTeX、PyMuPDF、Pillow が必要です。問題冊子も生成するため、既存の原稿ディレクトリのプリアンブルが必要です。生成物はリポジトリに含め、通常のサイトビルドでは再生成しません。

返却冊子だけの変更なら `npm run moshi:sample -- --kind return` で再生成できます。問題冊子と原稿ディレクトリには触れません。

公開前に `npm run lint`、`npm run check`、`npm run build`、`npm run check:html` を実行してください。
